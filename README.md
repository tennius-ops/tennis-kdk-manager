# 🎾 테니스 KDK 대진표 & 전적 관리 매니저

> **국밥툴즈 스타일 KDK · 한울 AA · 한울 AB 자동 로테이션 대진표 및 실시간 순위/전적 관리 웹 애플리케이션**

---

## ✨ 주요 기능

1. **⚡ 3가지 대진 방식 지원**
   - **KDK 방식**: 4~24명 참가자 지원, 1인당 경기 수(3~6경기) 자유 설정, 파트너 및 상대 자동 로테이션
   - **한울 AA 방식**: 5~16명 지원 (박현덕 님의 정통 한울방식 2코트 최적화 진행표 원본 탑재)
   - **한울 AB 방식**: 8~16명 지원 (남녀 혼합복식 / 1-2그룹 매칭 전용 공식 진행표)
2. **⚖️ 실력별 그루핑 (상급 / 중급 / 하급)**
   - 상급자끼리 같은 팀으로 묶이지 않도록 하고, 양 팀의 실력 격차를 최소화하는 밸런스 매칭
3. **🔍 공평성 검산 요약 카드**
   - 전원 동일 경기 수 여부, 1인당 경기 수, 파트너 중복 횟수(0쌍 목표), 상대 만남 균등도 실시간 자동 검산
4. **📋 간편한 명단 입력 (카톡 복사-붙여넣기)**
   - 카카오톡 단톡방 투표/참가 명단을 한 줄에 한 명씩 그대로 복사해 붙여넣으면 자동 인원 인식
5. **🏟️ 코트별 회차 분배 & 실시간 점수 입력**
   - 사용 코트 수(1~8면)에 따라 동시 진행 경기를 회차별로 스마트 그룹화
   - 실시간 점수 입력 및 승리 팀 하이라이트 표시
6. **🏆 실시간 개인 순위표 & 통계**
   - 승리 수, 패배, 득점, 실점, 득실차, 승률 자동 계산 및 실시간 랭킹 산출
7. **💾 로컬 저장 & 개인별 누적 토탈 승리 수 (명예의 전당)**
   - 브라우저 LocalStorage에 대회 결과 영구 저장
   - 저장된 모든 대회의 전적을 합산한 개인별 누적 최다승 랭킹 및 대회 기록 관리
8. **🖨️ 인쇄 최적화 & 테스트용 점수 자동채우기 지원**

## 🛠️ 기술 스택
- **HTML5**
- **CSS3** (반응형 모바일 지원, 테니스 코트 테마)
- **JavaScript (Vanilla ES6+)** (KDK 몬테카를로 최적화 스케줄러, 한울 매핑 알고리즘)
